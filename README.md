# ControleDeFrotaDeTaxi_ConsoleAPP
Um aplicativo do Console que tem como intuito controlar uma frota de táxi com 20 veículos

## ✦ Sobre
Projeto realizado em sala de aula para a matéria de programação estruturada do curso Análise e Desenvolvimento de Sistemas

## ✦ Funcionalidades
- [x] Adicionar corridas e seus respectivos valores para qualquer um dos 20 veículos na frota de táxi.
- [x] Ver tabela de veículos, ganhos e lucro total.
- [x] Ver carro com maior lucro e sua porcentagem nos lucros.
- [x] Ver carro com menor lucro e sua porcentagem nos lucros(carros sem lucro não são contados).
- [x] Zerar os valores de todos os carros.
- [x] Sair do Console.
